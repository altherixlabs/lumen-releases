# Altherix Lumen: downloads

Installers for **Altherix Lumen**, offline lyrics projection software for churches, for macOS and Windows.

**Download from [altherix.in/downloads](https://altherix.in/downloads/)**, or pick a version under [Releases](https://github.com/altherixlabs/lumen-releases/releases). Each release lists SHA-256 checksums in `SHA256SUMS.txt`.

- macOS 12 or later (Apple silicon and Intel): `Altherix-Lumen-mac-universal.dmg`
- Windows 10 or 11, 64-bit: `Altherix-Lumen-win-x64-setup.exe`
